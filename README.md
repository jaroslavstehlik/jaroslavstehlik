#### Shipped work

- **[Beat Saber](https://jaroslavstehlik.com/#beat-saber)** (2018): built the arcade version for Skonec: token-based menus, hardware SDK integration and testing with a real token acceptor. Worked on the main game's UI and fixed its post-processing for mixed reality capture. *C#, Unity*
- **[LIV SDK](https://jaroslavstehlik.com/#liv-sdk)** (2018): the bridge between VR/AR games and the LIV app, which Meta uses for official Quest trailers. Redesigned the SDK core several times and helped studios integrate it, including Beat Saber, Budget Cuts and Synth Riders. *Rust, C++, C#, Unity*
- **[LIV Avatars & Overlay](https://jaroslavstehlik.com/#xr)** (2019): built the core avatar system, scriptable cameras and the overlay UI that renders sharp 3D UI next to a running game. *C++, C#, HLSL, SteamVR, OpenXR, VRM*
- **[Gorilla Tag Tablet](https://jaroslavstehlik.com/#gorilla-tag-tablet)** (2025): contributed to the Rust core library of LIV Creator Kit, integrated it into Gorilla Tag on Quest, designed the in-world tablet interaction and profiled it with Perfetto. *Rust, C++, C#, Unity, Meta Quest*
- **[Blue Effect VR](https://jaroslavstehlik.com/#blue-effect-vr)** (2016): led development of a SteamVR horror game with adaptive enemies, fully real-time lighting and in-game mixed reality capture. *C#, Cg shaders, Unity*
- **[Mimpi Dreams](https://jaroslavstehlik.com/#mimpi-dreams)** (2015): led development of a puzzle-platformer for iOS, Android and Steam; Apple Game Award in China and multiple App Store features. *C#, Unity*
- **[BOAR](https://jaroslavstehlik.com/#boar)** (2022): software for a live robotic art performance by Federico Díaz, with an audience AR app. *C++, C#, Unity, ARKit, OpenCV*

#### Lab: research and prototypes

- **LIV App in Rust** (2025): a faster LIV app, independent of a single VR runtime; camera calibration across coordinate systems. *Rust, Tokio, WGPU, Eigen, OpenXR*
- **Volumetric Video** (2022): Kinect recordings to in-game volumetric capture and playback; [US patent 11769299](https://patents.google.com/patent/US11769299B1). *Rust, C++, GLSL, compute shaders*
- **Tyre Physics** (2026): a soft-body solver benchmark (VBD, XPBD, Projective Dynamics) that became a tyre demo.
- **Autonomous Play Tester** (2026): a 2D platformer play tester with sub-millisecond movement planning. *Rust, Bevy*
- **Cinematic Camera** (2026): an autonomous cameraman with real-time navmesh generation and target tracking.

More on the [simulations](https://jaroslavstehlik.com/#simulations) and [robotics](https://jaroslavstehlik.com/#robotics) pages of the portfolio.
